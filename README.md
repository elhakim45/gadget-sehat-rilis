# Gadget Sehat — Unduhan untuk Pembeli

Aplikasi pendamping orang tua untuk memantau dan mengatur gadget Android anak.
Satu aplikasi dipasang di **gadget orang tua** dan **gadget anak**.

## Unduh

➡️ **[Unduh versi terbaru](https://github.com/elhakim45/gadget-sehat-rilis/releases/latest)**: pilih file `GadgetSehat-v….apk` di bagian *Assets*.

## Cara memasang
1. Buka file APK yang sudah diunduh, izinkan "Instal dari sumber ini" bila diminta.
2. Pasang di gadget orang tua dan gadget anak.
3. Ikuti petunjuk di aplikasi: setujui halaman persetujuan, pilih **Gadget Orang Tua** atau **Gadget Anak**.
4. Aktifkan lisensi di gadget orang tua (bisa coba gratis 1 hari).

Pembaruan berikutnya muncul otomatis di dalam aplikasi; data dan pengaturan tidak hilang.
